# parmahub
A responsive web platform for pharmacy students to access notes, practice quizzes , and use pharmacy related tools like dosage calculators and flash cards.

## Features
study notes organised by subject.
interactive multiple choice questions with instant feedback.
Flashcards for revision 
Dosage and BMI calculators
Clean and responsive UI
